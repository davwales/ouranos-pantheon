# Product Context - Ouranos Pantheon

## Purpose

Ouranos Pantheon appears to be a multi-module web application with two main functional areas:

1. Hermes - Likely an AI assistant/chat interface
2. Plutus - Financial market analysis and forecasting system

## User Needs

- **Hermes Users**: Need conversational AI assistance with tasks
- **Plutus Users**: Need financial market insights, price tracking, and forecasting tools

## Key User Flows

1. **Hermes**:

   - Assistant selection and creation
   - Conversation management
   - Step-by-step task assistance

2. **Plutus**:
   - Market exploration and symbol search
   - Price chart visualization
   - Recipe/strategy creation and management
   - Financial forecasting

## Experience Goals

- Consistent responsive experience across devices
- Intuitive navigation between modules
- Clear data visualization in Plutus
- Natural conversation flow in Hermes
