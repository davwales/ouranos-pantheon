# Project Brief - Ouranos Pantheon

## Overview

Ouranos Pantheon is a web application built with Next.js that appears to have multiple sections/modules:

- Hermes (likely related to chat/assistant functionality)
- Plutus (financial/stock market related features)
- Core UI components and services

## Key Features

- Responsive UI components (navigation, dialogs, data tables)
- Financial market data visualization (Plutus)
- Assistant/conversation interface (Hermes)
- Modern web stack (Next.js, TypeScript, GraphQL)

## Technical Stack

- Frontend: Next.js, React, TypeScript
- Styling: Tailwind CSS (via globals.css)
- State Management: Custom stores (plutus_store.tsx, global_state.tsx)
- API: GraphQL (gql directory)
- UI: Shadcn/ui components

## Project Structure

- src/app: Next.js app router structure
- src/components: Shared UI components
- src/lib: Utility functions
- src/services: API/service layer
- src/hooks: Custom React hooks
